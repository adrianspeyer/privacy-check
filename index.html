A LITTLE CONTEXT

A snapshot.
Not a privacy certificate.

This tool shows what this page can observe in this browser. It cannot see your settings on other sites, prove that trackers are blocked, or measure how unique you are.

Results are kept in this tab and are not uploaded. The optional public-IP comparison contacts this site’s host, which sees your IP as it does with other requests. The host may retain standard access logs.

Try changing a browser setting, then rescan to see what changes. Permission checks only read existing states; they never ask for camera, microphone, or location access.

Save report downloads a file with your findings and device details. Public IP addresses and the canvas hash are excluded. Review the file before sharing it.
